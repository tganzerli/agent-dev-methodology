# Knowledge Index

> Catalog of **knowledge** pages (domains, entities, services, flows, pages, contracts, ADRs, sources). Updated on every `/wiki-sync` or source ingest.
>
> The **work** catalog (tasks/plans/executions) lives in [[work/_index]] instead — generated by `/work-index`, never hand-edited (see conventions.md §"work index is generated").
>
> Convention: `[[path/to/page]] — status — one-line description.` One physical line per entry, ≤300 chars; the file stays under 20 KB (`/wiki-lint` gate `index-format`).
>
> Directories with a **generated** catalog (`decisions/`, `cross-cutting/`, `sources/external/`, `postmortems/` — `/wiki-index`) get one pointer here, not a copy of their list: hand-kept copies all drifted.
>
> In a monorepo installation (see `modules/monorepo/`), this catalog is organized under `## Apps` and `## Packages` subsections instead of the flat sections below — see that module's README for the reorganized layout.
